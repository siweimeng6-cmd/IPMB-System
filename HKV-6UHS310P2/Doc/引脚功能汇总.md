# HKV-6UHS310P2 项目引脚及功能汇总

> **项目说明** ：本项目基于 STM32F103 系列 MCU，运行 FreeRTOS 实时操作系统，作为板级控制器（BMC）实现电压/温度采集、风扇 PWM 控制、IPMB 总线通信、上下电控制、键盘输入及状态指示等功能。
>
> **MCU 型号** ：STM32F103 (Cortex-M3) 
> **参考工程版本** ：V1.1 / 2026-03-11

---

## 一、端口总览

| 端口 | 已使用引脚 | 未使用引脚 | 备注 |
|------|------------|------------|------|
| GPIOA | PA0, PA1, PA4–PA12, PA13(SWDIO), PA14(SWDK), PA15 | PA2, PA3(预留) | PA2/PA3 注释保留为 UART2 (IPMB-A) |
| GPIOB | PB0, PB1, PB6, PB7, PB8, PB9, PB10, PB11, PB12–PB15 | PB2(BOOT1), PB3, PB4, PB5 | PB3/PB4/PB5 注释保留 |

| GPIOE | – | – | 未使用 |

> **复用功能** ：I2C1、I2C2、UART4、UART5、TIM6、TIM8 详见"五、复用外设引脚映射"。

## 六、功能模块汇总

### 6.1 模拟量采集 — ADC (5 通道)

| 通道 | 引脚 | 监测对象 | 量程 | 换算系数 |
|------|------|----------|------|----------|
| ADC_CH6 | PA6 | +12V_HOT | 0–12V | 0.084 |
| ADC_CH7 | PA7 | 0.75V_DDRPHY_M | 0–0.75V | 1.01 |
| ADC_CH8 | PB0 | 0.75V_DDRPHY_S | 0–0.75V | 1.01 |
| ADC_CH9 | PB1 | 3.8V_V_VSYS | 0–3.8V | 0.31 |
| ADC_CH10 | PC0 | 3.3V_VRD_MOS | 0–5V | 0.2 |

> 采集方式：ADC1 扫描模式 + DMA1_Channel1 循环搬运 20 次，软件取平均后换算实际电压。

### 6.2 温度采集 — 软件模拟 I2C

- **总线** ：PB8 (SCL) / PB9 (SDA) — GPIO 模拟
- **从设备** ：2× LM75A 温度传感器
  - 地址 0x90（板内 0）
  - 地址 0x92（板内 1）
- **数据格式** ：11-bit 二进制补码，0.125°C/LSB
- **结果输出** ："ADDR0x90:xx.x C" 与 "ADDR0x92:xx.x C"

### 6.3 风扇调速 — PWM

- **引脚** ：PC8 (TIM8_CH3)
- **频率** ：`PWM_Freq = 72MHz / (71+1) / 200 ≈ 5KHz`
- **调速策略** （根据 LM75A 地址 0x92 的温度）：
  - T < 0°C → 占空比 0%
  - 0°C ≤ T < 40°C → 25%
  - 40°C ≤ T < 50°C → 50%
  - 50°C ≤ T < 60°C → 75%
  - T ≥ 60°C → 100%

### 6.4 主板上下电控制

| 信号 | 引脚 | 电平逻辑 |
|------|------|----------|
| PWR_CTL（上/下电） | PA4 | 低=上电，高=下电 |
| BMC_CTRL_SYSRST（复位） | PA12 | 低=正常，高=复位（由 PC5 按键控制） |
| VP0_SYSRESET#（按键） | PC5 | 上拉输入，低电平触发复位 |

> 串口命令：`poweron` / `poweroff`（UART4 接收，命令解析后置标志位，由 GPIO_Task 处理）

### 6.5 IPMB 总线

- **IPMB-A** ：硬件 I2C1（PB6/PB7），本机从机地址 0x0A
- **IPMB-B** ：硬件 I2C2（PB10/PB11），本机从机地址 0x0B
- 速率 400KHz，主从收发 + 事件/错误中断

### 6.6 状态指示灯

| 引脚 | 信号 | 频率 | 用途 |
|------|------|------|------|
| PA15 | LED_BMC_STA | 2Hz | 主板运行状态 |
| PC4 | LED_BMC_RESERVE | 2Hz | 备用状态灯 |
| PA1 | ALERT_JX | 2Hz | 告警灯（测试用） |

### 6.7 串口通信

| 串口 | 引脚 | 波特率 | 用途 |
|------|------|--------|------|
| UART4 | PC10/PC11 | 115200 | 调试 `printf` + 接收 poweron/poweroff 指令 |
| UART5 | PC12/PD2 | 115200 | 与 CPU 通信；接收 `?` → 触发上报系统健康信息（电压/温度/PWM） |

### 6.8 IPMB 双路从机（已实现）

| 总线 | 外设 | SCL/SDA | 7-bit 地址 | 速率 |
|------|------|---------|------------|------|
| IPMB-A | I2C1（从机） | PB6/PB7 | 0x8E | 100KHz |
| IPMB-B | I2C2（从机） | PB10/PB11 | 0x8E | 100KHz |

**实现命令**（详见 [User/ipmb/](User/ipmb/)）：

| 命令 | Cmd | netFn | 用途 |
|------|-----|-------|------|
| Get Device ID | 0x01 | 0x06 | 返回设备 ID / 硬件版本 / 固件版本 / IPMI 版本 / 厂商 ID / 产品 ID |
| Get Device SDR Info | 0x21 | 0x04 | 返回 SDR 数量 / 时间戳 |
| Get SDR | 0x23 | 0x04 | 占位（返回 0xFF × 16） |
| Get Sensor Reading | 0x2D | 0x04 | 返回指定 sensor 当前值（电压/温度/风扇） |
| Get Board System Status | 0x16 | 0x06 | 返回 14 字节系统状态（CPU 在位/利用率/带宽/温度/OS/FW） |
| Get Slot | 0x15 | 0x06 | 返回槽位号（GA0~GA4 GPIO） |
| Set FRU Activation | 0x0C | 0x2C | 上电/断电/复位/软关机/软复位/阈值超限/风扇档位/IPMC 版本/I2C 速率 |
| Platform Event Message | 0x02 | 0x04 | 阶段 1 占位，仅返回 CC=OK |

**任务** ：`IPMB_A_Task` 与 `IPMB_B_Task`（优先级 3，栈 512 字），由中断事件信号量唤醒。

**数据源映射** ：

| sensor num | 数据来源 |
|-----------|----------|
| 0x04 (温度0) | LM75A @ 0x90 → `board_temp0[0]` |
| 0x20 (温度1) | LM75A @ 0x92 → `board_temp1[0]` |
| 0x03 (12V) | PA6 ADC → `stADC_Data.adc_voltage_val[0]` |
| 0x16 (3.3V) | PC0 ADC → `stADC_Data.adc_voltage_val[4]` |
| 0x19 (0.75V) | PA7/PB0 ADC 平均 |
| 0x41 (风扇) | `pwm_get_duty()` |
| Get Slot | GA0~GA4 GPIO |

## 八、注意事项

1. **JTAG 禁用** ：上电初始化时关闭 JTAG（`GPIO_Remap_SWJ_JTAGDisable`），PA15 释放为 GPIO 用途，否则 LED_BMC_STA 无法工作。
2. **调试接口** ：仅保留 SWD（PA13/PA14），不可用 JTAG 调试。
3. **软件 I2C 切换** ：通过 `bsp_mo_i2c.h` 中的 `TEST_IIC1_MONI` 宏切换 SCL/SDA 至 PB6/PB7 或 PB8/PB9。
4. **硬件 I2C 冲突** ：硬件 I2C1 (PB6/PB7) 和软件模拟 I2C 默认引脚不重合；`bsp_i2c.c` 中 `I2C_GPIO_Config` 会同时初始化 PB6/PB7/PB10/PB11 的复用开漏模式，需注意与软件 I2C 切换的互斥。
5. **PD2 复用** ：当前仅作为 UART5_RX 浮空输入；项目备注中提及"主板 PCIe 复位信号输入"功能尚未启用。
6. **晶振/RTC** ：PC13–PC15 在头文件中以注释方式保留，用于 32.768KHz 晶振与 RTC 入侵检测，代码内暂未使用。
